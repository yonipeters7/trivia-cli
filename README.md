# CLI Trivia Game

A simple command-line trivia game I built with Node.js. Answer questions before time runs out!

## What It Does

You get 60 seconds to answer trivia questions. Type A, B, C, or D for each question and see if you got it right. At the end you get a score and some feedback on how you did.

## How to Run It

Just clone the repo and run:
```bash
node trivia.js
```

No setup needed, just Node.js.

## How to Play

1. Press Enter to start
2. Read the question
3. Type A, B, C, or D
4. Get instant feedback if you're right or wrong
5. Try to answer all questions before time runs out

## Features

- 60 second timer
- Immediate feedback on answers
- Score tracking
- Stats at the end
- Questions displayed one at a time

## What I Used

- Node.js
- JavaScript (functions, arrays, timers, etc.)
- Readline for user input

## Customize It

You can easily change things:
- Add more questions in the `questions` array
- Change the timer duration
- Modify the feedback messages
